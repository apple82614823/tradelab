# TradeLab（交易实验室）

实验性交易工程参考。

[English](README.md)

这是一个从私有开发阶段整理出来的 Python 币安 U 本位合约研究项目，包含策略判断、订单执行、持久化状态、交易审计和 SQLite 信号数据保留机制。开发过程中使用了 ChatGPT 和 Codex 辅助。

**它不是经过验证的盈利产品。测试通过不等于策略有效，也不等于适合真实账户使用。项目与 Binance、OpenAI 不存在官方隶属或背书关系。**

## 当前范围

- 多策略模式的活跃策略集为 N01–N05，不要求连赢资格；正常入场条件和执行检查仍然有效。
- N06–N25 的源码与测试为历史兼容保留，不代表当前会产生这些策略的新交易机会。
- `.env.example` 默认仍选择早期单策略路径。设置 `MULTI_STRATEGY_ENABLED=true` 才选择 N01–N05；这与是否启用实盘是两个独立开关。
- 不附带真实密钥、服务器配置、数据库、日志、账户记录或历史收益。
- 私有版本针对单条历史记录的维护身份，在公开版中换为固定的合成示例。因此公开版 schema **有意不兼容原私有数据库**；不要使用原数据库，也不要把示例值当成真实记录的授权。
- 不把历史纸单结算兼容能力宣传为完整的全策略回测平台。

## 推荐先运行测试

环境：macOS 或 Linux、Python 3.9+、Git。代码依赖 POSIX 文件锁和文件系统行为；本版不支持原生 Windows。已验证的平台和解释器组合以实际验证报告为准。

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p 'test_*.py'
```

测试使用本地构造的数据和模拟接口，不需要真实账户或密钥。`tests/*scale_gate.py` 是单独选择执行的资源测试，不属于普通 discovery 命令。

## 可选的模拟运行探索

复制 `.env.example` 为 `.env`，保持 `BINANCE_DRY_RUN=true`，API Key 和 Secret 留空。阅读参数后再运行 `python main.py`。

运行主程序会请求公开行情并写入本地文件，与离线测试不同。数据库初始化和旧库升级是显式步骤，新建或旧版数据库可能被拒绝，直到完成适用的 schema 准备。本次公开候选不承诺“一条命令即可交易”，不要拿真实生产数据库试运行。

示例中保留的余额 20% 目标风险和 95% 保证金上限，是激进的历史研究参数，不是推荐的账户设置。5R 是计划规则，不是实际收益保证。不要为了体验开源代码而启用实盘。
